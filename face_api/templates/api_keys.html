Developer Integration Guide

API reference for State Government development teams

expand_more

All endpoints require X-API-Key: vsk_xxxxx header. Send Idempotency-Key on uploads to prevent duplicates.

1 — Health Check

curl GET /api/v1/health \
  -H "X-API-Key: vsk_YOUR_KEY"

2 — Upload Wanted Person

curl POST /api/v1/wanted \
  -H "X-API-Key: vsk_YOUR_KEY" \
  -H "Idempotency-Key: FIR-001" \
  -F "image=@photo.jpg" \
  -F "name=John Doe" \
  -F "crime=Robbery" \
  -F "case_number=FIR/2026/001"

3 — Verify Upload

curl GET /api/v1/wanted/{person_id} \
  -H "X-API-Key: vsk_YOUR_KEY"

Python Example

import requests
r = requests.post(
  f"{SERVER}/api/v1/wanted",
  headers={"X-API-Key": KEY,
           "Idempotency-Key": "FIR-001"},
  files={"image": open("photo.jpg","rb")},
  data={"name":"John Doe","crime":"Robbery"}
)
print(r.json())
