Integration Guide for State Government Systems

Step 1 — Health Check

curl -X GET https://your-server/api/v1/health \
  -H "X-API-Key: vsk_YOUR_KEY_HERE"

Expected: {"ok": true, "status": "connected", "state": "Tamil Nadu"}

Step 2 — Upload Wanted Person

curl -X POST https://your-server/api/v1/wanted \
  -H "X-API-Key: vsk_YOUR_KEY_HERE" \
  -H "Idempotency-Key: unique-request-id-001" \
  -F "image=@suspect_photo.jpg" \
  -F "name=John Doe" \
  -F "crime=Robbery" \
  -F "case_number=FIR/2026/001"

Expected: {"ok": true, "person_id": "uuid", "classification": "wanted"}

Step 3 — Verify Upload

curl -X GET https://your-server/api/v1/wanted/{person_id} \
  -H "X-API-Key: vsk_YOUR_KEY_HERE"
Python example ▸ 
import requests

API_KEY = "vsk_YOUR_KEY_HERE"
SERVER  = "https://your-server"

response = requests.post(
    f"{SERVER}/api/v1/wanted",
    headers={
        "X-API-Key":       API_KEY,
        "Idempotency-Key": "unique-request-001",
    },
    files={"image": open("suspect.jpg", "rb")},
    data={
        "name":        "John Doe",
        "crime":       "Robbery",
        "case_number": "FIR/2026/001",
    }
)
print(response.json())
