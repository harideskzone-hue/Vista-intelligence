How to connect a remote camera ▸

1. Install relay on the camera device:

pip install requests websocket-client opencv-python

2. Run camera_relay.py near your camera:

python camera_relay.py \ --camera-url http://CAMERA_IP:8080/video \ --server-ws ws://SERVER_IP:5001/api/camera/ws/cam_remote_1 \ --camera-id cam_remote_1 \ --fps 15

Replace CAMERA_IP with your IP Webcam app IP,
SERVER_IP with this machine's IP or your tunnel URL (ngrok/cloudflared/VPS).
Transport is configurable: ws:// for LAN, wss:// for internet.
